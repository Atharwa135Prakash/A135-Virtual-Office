A135 Virtual Office — Live Hosting
1. Upload index.html to a static website host (Netlify or GitHub Pages).
2. For cross-device storage, configure Firebase using FIREBASE_SETUP.txt.
3. In the hosted site, open Settings & Data → Cloud sync setup, paste Firebase web config JSON, and click Save & connect Firebase.
4. Sign in with Google and use the same account on all devices.
Hosting alone does not sync local browser storage.
